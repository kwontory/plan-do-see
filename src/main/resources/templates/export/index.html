1. 내보내기

자료 내보내기

지금까지 저장한 계획, 할 일, 실행 기록, 회고를 JSON 파일 하나로 내려받습니다.

포함되는 자료

  • 계획
  • 계획 수정 이력
  • 할 일
  • 태그와 할 일-태그 연결
  • 실행 기록
  • 완료 기록
  • 회고와 개선점 이관 정보
  • 모든 ID와 서로의 연결 관계
  • 날짜(yyyy-MM-dd)와 시각(시간대 포함)
  • 시간 값(모두 분 단위 정수)

포함되지 않는 자료

  • 삭제한 할 일과 그 할 일의 실행 기록·완료 기록·태그 연결
  • 비밀번호, 인증 토큰, 세션 값, 서버 접속 정보 같은 비밀값

파일 형식

  • 파일 이름: plandosee-export-YYYYMMDD.json(내려받은 날짜)
  • 문자 인코딩: UTF-8
  • 스키마 버전과 내보낸 시각, 시간대(Asia/Seoul)가 파일 맨 위에 들어 있습니다.

지금은 로그인이 없어 이 내려받기 주소도 링크를 아는 누구나 사용할 수 있습니다.
